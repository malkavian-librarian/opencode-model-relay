# opencode-model-relay v1.0 (spike + failover + handover) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1.0 of an OpenCode plugin that detects hard model failures, picks the next model from a configured chain, writes a structured handover, and resumes the session on the new model, with a plain narrator, a switch log and `/relay status`.

**Architecture:** A pure core (classifier, strategy, redact, handover rendering, config) wrapped by a thin impure shell (controller, switcher, OpenRouter client, state store, hooks). All main-model traffic stays inside OpenCode (`client.session.prompt({model})`); only the optional handover writer calls OpenRouter directly, and only after explicit consent. Phase 0 is a throwaway spike that settles the unverified API questions before the shell is built.

**Tech Stack:** TypeScript (ESM), Node 22 for tests, vitest, tsup, zod 3, jsonc-parser, `@opencode-ai/plugin` (peer + dev dependency).

**Spec:** `docs/superpowers/specs/2026-10-18-model-relay-design.md` (v2). This plan implements phases 0, 1, 2 and 6 for the **v1.0** cut. Out of this plan (own plans later): judge, tiers' quality path, `chain-recover` / `escalate` modes, British pools (v1.1); full ledger, `stats.json`, `/relay stats`, `/relay purge`, `/relay pick` (v1.2).

## Global Constraints

- No request proxying: main-model traffic always goes through OpenCode. Only helper calls go direct to OpenRouter.
- OpenRouter key from env var only (default `OPENROUTER_API_KEY`); never in config, logs, ledger, or thrown errors.
- `openrouter.baseUrl` must be `https`, host `openrouter.ai` unless `allowCustomBaseUrl: true`; requests use `redirect: "manual"`.
- Data egress is opt-in: nothing is sent to OpenRouter unless `privacy.consent: true`. OpenRouter requests send `provider.data_collection: "deny"`.
- Everything sent to OpenRouter passes through `redact()` first; tool output from sensitive paths is dropped.
- Transcripts and tool output are untrusted data. The handover message must state it is a model-generated summary, not user instructions, and carry the user's last request verbatim.
- Config is read from the user config dir only (never the project). Config file: `~/.config/opencode/opencode-model-relay.jsonc` (OpenCode itself uses `~/.config/opencode` on every platform, including this Windows machine). Data dir: `~/.local/share/opencode-model-relay`. `XDG_CONFIG_HOME` / `XDG_DATA_HOME` override. Path settings must resolve under these dirs. Config file capped at 64 KB.
- Ledger/switch log holds metadata only (no prompt or response text); reasons are enums; session ids are HMAC'd with a per-install random salt.
- Skip sessions with a `parentID` (subagents). Never switch on `overflow`, `user_abort` or `unknown`.
- Any internal failure must leave the session usable on its current model; hooks never throw.
- Dependencies limited to `zod` and `jsonc-parser`; `@opencode-ai/plugin` is a peer dependency.
- Model strings are `providerID/modelID`; split on the **first** `/` only (`openrouter/z-ai/glm-5.3` -> provider `openrouter`, model `z-ai/glm-5.3`).
- Windows shell: `git` is not on PATH. In each PowerShell session run once: `Set-Alias git "<path-to-git.exe>"`. Chain commands with `;`, not `&&`. Never commit `.env`, `dist/`, `node_modules/`.
- Before every `git push`: run the `security-review` skill (from inside the repo) and fix CRITICAL/HIGH findings.
- Working directory for every task: `<repo>`.

## Review Focus

- Error payload that is `null`, a string, or an object of an unexpected shape: classifier returns `unknown` (not switchable) and never throws. (Task 4)
- The user presses Esc while a switch is in progress, or Esc alone: treated as `user_abort`, never as a failure, never causes a loop. (Tasks 7, 12)
- Only one model in the chain (or all others cooling/blacklisted): exhausted, toast shown, session untouched. (Tasks 6, 12)
- Huge or secret-bearing tool output (5 MB `cat .env`, private key block): truncated, redacted, omitted for sensitive paths, and never sent anywhere when consent is off. (Tasks 5, 9, 12)
- Config file missing, unreadable, invalid JSONC, or invalid schema: plugin still loads with defaults and warns once. (Tasks 3, 13)

```ts
import type { Plugin } from "@opencode-ai/plugin"
import fs from "node:fs"
import path from "node:path"
import os from "node:os"

const OUT = path.join(os.homedir(), ".local", "share", "opencode-model-relay", "spike")
fs.mkdirSync(OUT, { recursive: true })
const dump = (name: string, data: unknown) =>
  fs.appendFileSync(path.join(OUT, name + ".jsonl"), JSON.stringify({ t: Date.now(), data }) + "\n")

export const server: Plugin = async ({ client }) => ({
  config: async (input: any) => {
    input.command = { ...(input.command ?? {}), relay: { template: "relay", description: "relay spike" } }
  },
  "command.execute.before": async (input: any, output: any) => {
    dump("command", { input })
    if (input.command === "relay") {
      output.parts = []
      await client.tui.showToast({ body: { message: "relay spike command ran", variant: "info" } })
    }
  },
  "chat.message": async (input: any, output: any) => {
    dump("chat.message", { input, model: output.message?.model })
    if (process.env.SPIKE_PIN) {
      const [providerID, ...rest] = process.env.SPIKE_PIN.split("/")
      output.message.model = { providerID, modelID: rest.join("/") }
    }
  },
  event: async ({ event }: any) => {
    if (["session.error", "session.status", "session.idle", "message.updated"].includes(event.type)) dump("event-" + event.type, event)
    if (event.type === "session.idle" && process.env.SPIKE_DUMP_MESSAGES) {
      const r = await client.session.messages({ path: { id: event.properties.sessionID } })
      dump("messages", r.data)
    }
  },
})
export default { id: "relay-spike", server }
```

```ts
export interface ModelRef { providerID: string; modelID: string }

export function parseModel(s: string): ModelRef {
  const i = s.indexOf("/")
  if (i <= 0 || i === s.length - 1) throw new Error(`Invalid model "${s}": expected "provider/model"`)
  return { providerID: s.slice(0, i), modelID: s.slice(i + 1) }
}
export function modelKey(m: ModelRef): string { return `${m.providerID}/${m.modelID}` }

export type FailureKind =
  | "rate_limit" | "quota" | "auth" | "free_tier_403" | "server_5xx"
  | "timeout" | "model_not_found" | "overflow" | "user_abort" | "unknown"

export interface Classified {
  kind: FailureKind
  retryable: boolean
  retryAfterMs?: number
  permanent: boolean
  switchable: boolean
}

export type OcPart =
  | { type: "text"; text: string; synthetic?: boolean }
  | { type: "tool"; tool: string; state: { status: string; input?: any; output?: string; error?: string } }
  | { type: string; [k: string]: unknown }

export interface OcMessage {
  info: { id: string; role: "user" | "assistant"; providerID?: string; modelID?: string; agent?: string; mode?: string }
  parts: OcPart[]
}

export interface ClientLike {
  session: {
    get(a: { path: { id: string } }): Promise<{ data?: { parentID?: string } }>
    messages(a: { path: { id: string } }): Promise<{ data?: OcMessage[] }>
    abort(a: { path: { id: string } }): Promise<unknown>
    prompt(a: {
      path: { id: string }
      body: { model: ModelRef; agent?: string; parts: { type: "text"; text: string }[] }
    }): Promise<unknown>
  }
  tui: { showToast(a: { body: { message: string; variant?: "info" | "success" | "warning" | "error" } }): Promise<unknown> }
}
```

```ts
import { z } from "zod"
import { parse, type ParseError } from "jsonc-parser"
import fs from "node:fs"
import os from "node:os"
import path from "node:path"
import { DEFAULT_TEMPLATE, DEFAULT_WRITER_PROMPT } from "./defaults"

const modelStr = z.string().regex(/^[^/\s]+\/\S+$/, 'expected "provider/model"')

export const ConfigSchema = z
  .object({
    mode: z.literal("chain-sticky").default("chain-sticky"),
    tiers: z
      .object({
        primary: modelStr.optional(),
        secondary: z.array(modelStr).default([]),
        tertiary: z.array(modelStr).default([]),
      })
      .strict()
      .default({}),
    privacy: z
      .object({ consent: z.boolean().default(false), zdr: z.boolean().default(false) })
      .strict()
      .default({}),
    openrouter: z
      .object({
        keyEnv: z.string().min(1).default("OPENROUTER_API_KEY"),
        baseUrl: z.string().url().default("https://openrouter.ai/api/v1"),
        allowCustomBaseUrl: z.boolean().default(false),
      })
      .strict()
      .default({}),
    handover: z
      .object({
        model: z.string().min(1).default("z-ai/glm-5.2"),
        writerPrompt: z.string().min(1).default(DEFAULT_WRITER_PROMPT),
        messageTemplate: z.string().min(1).default(DEFAULT_TEMPLATE),
        maxToolChars: z.number().int().positive().default(1500),
        maxTranscriptChars: z.number().int().positive().default(60000),
        maxCallsPerSession: z.number().int().nonnegative().default(3),
      })
      .strict()
```

```ts
import type { Classified, FailureKind } from "./types"

const RE = {
  freeTier: /free tier can only be used from within opencode|FreeTierError/i,
  quota: /insufficient[_ ]?(credit|quota|funds)|exceeded your current quota|billing|credit balance|out of credits/i,
  overflow: /context (length|window)|maximum context|too many tokens|prompt is too long|exceeds the (model'?s )?(context|limit)/i,
  notFound: /model\b[^.\n]{0,60}(not found|does not exist)|unknown model/i,
  timeout: /timed? ?out|ETIMEDOUT|ECONNRESET|ECONNREFUSED|socket hang up/i,
}

const unknown: Classified = { kind: "unknown", retryable: false, permanent: false, switchable: false }
const mk = (kind: FailureKind, permanent: boolean, extra: Partial<Classified> = {}): Classified => ({
  kind, retryable: !permanent, permanent, switchable: true, ...extra,
})

export function classify(err: unknown): Classified {
  try {
    if (typeof err !== "object" || err === null) return unknown
    const e = err as Record<string, any>
    const name = typeof e.name === "string" ? e.name : ""
    const data = (typeof e.data === "object" && e.data !== null ? e.data : e) as Record<string, any>
    const status = typeof data.statusCode === "number" ? data.statusCode : undefined
    const text = `${data.responseBody ?? ""} ${data.message ?? ""}`

    if (name === "MessageAbortedError") return { kind: "user_abort", retryable: false, permanent: false, switchable: false }
    if (name === "ProviderAuthError") return mk("auth", true)
    if (RE.overflow.test(text)) return { kind: "overflow", retryable: false, permanent: false, switchable: false }
    if (RE.freeTier.test(text)) return mk("free_tier_403", true)
    if (status === 402) return mk("quota", true)
    if (status === 429) {
      if (RE.quota.test(text)) return mk("quota", true)
      const h = data.responseHeaders as Record<string, string> | undefined
      const secs = h ? Number(h["retry-after"] ?? h["Retry-After"]) : NaN
      return mk("rate_limit", false, Number.isFinite(secs) ? { retryAfterMs: secs * 1000 } : {})
    }
    if (status === 401 || status === 403) return mk("auth", true)
    if (status === 404 || RE.notFound.test(text)) return mk("model_not_found", true)
    if (status !== undefined && status >= 500) return mk("server_5xx", false)
    if (RE.timeout.test(text)) return mk("timeout", false)
    return unknown
  } catch {
    return unknown
  }
}
```

```ts
const PEM = /-----BEGIN [A-Z ]*PRIVATE KEY-----[\s\S]*?-----END [A-Z ]*PRIVATE KEY-----/g
const TOKENS: RegExp[] = [
  /sk-[A-Za-z0-9_-]{16,}/g,
  /gh[pousr]_[A-Za-z0-9]{20,}/g,
  /AKIA[0-9A-Z]{16}/g,
  /eyJ[A-Za-z0-9_-]{8,}\.[A-Za-z0-9_-]{8,}\.[A-Za-z0-9_-]{8,}/g,
  /Bearer\s+[A-Za-z0-9._~+/-]{16,}=*/g,

const KEY_LINE = /^([ \t]*[A-Za-z][A-Za-z0-9_]*(?:KEY|TOKEN|SECRET|PASSWORD|PASSWD)[A-Za-z0-9_]*)[ \t]*=[ \t]*.+$/gim

export function redact(text: string): string {
  let out = text.replace(PEM, "[REDACTED PRIVATE KEY]")
  for (const re of TOKENS) out = out.replace(re, "[REDACTED]")
  out = out.replace(KEY_LINE, (_m, name: string) => `${name.trim()}=[REDACTED]`)
  return out
}

const SENSITIVE = /(^|[\\/])\.env(\..*)?$|id_rsa|id_ed25519|\.pem$|\.p12$|\.pfx$|(^|[\\/])credentials$|(^|[\\/])\.npmrc$|(^|[\\/])\.netrc$|(^|[\\/])secrets?\.(json|ya?ml)$/i
export function isSensitivePath(p: string): boolean {
  return SENSITIVE.test(p)
}

export function truncate(text: string, max: number): string {
  if (text.length <= max) return text
  const half = Math.floor(max / 2)
  return `${text.slice(0, half)}\n[truncated ${text.length - max} chars]\n${text.slice(text.length - half)}`
}
```

```ts
import type { RelayConfig } from "./config"
import type { Classified } from "./types"

export interface ModelHealth { permanent?: boolean; cooldownUntil?: number; failures?: number }

export type Decision =
  | { action: "switch"; to: string }
  | { action: "exhausted"; reason: "no_candidates" | "switch_cap" }

export function buildChain(cfg: RelayConfig, current: string): string[] {
  const list = [...(cfg.tiers.primary ? [cfg.tiers.primary] : []), ...cfg.tiers.secondary, ...cfg.tiers.tertiary]
  const seen = new Set<string>()
  const chain = list.filter((m) => (seen.has(m) ? false : (seen.add(m), true)))
  if (!cfg.tiers.primary) {
    const rest = chain.filter((m) => m !== current)
    return [current, ...rest]
  }
  return chain
}

export function nextModel(i: {
  chain: string[]; current: string; health: Record<string, ModelHealth>
  now: number; switchCount: number; maxSwitches: number
}): Decision {
  if (i.switchCount >= i.maxSwitches) return { action: "exhausted", reason: "switch_cap" }
  for (const m of i.chain) {
    if (m === i.current) continue
    const h = i.health[m]
    if (h?.permanent) continue
    if (h?.cooldownUntil !== undefined && h.cooldownUntil > i.now) continue
    return { action: "switch", to: m }
  }
  return { action: "exhausted", reason: "no_candidates" }
}

const MAX_COOLDOWN_MS = 3_600_000
export function recordFailure(
  health: Record<string, ModelHealth>, model: string, c: Classified, now: number, cooldownMs: number,
): void {
  const h = (health[model] ??= {})
  if (c.permanent) { h.permanent = true; return }
  h.failures = (h.failures ?? 0) + 1
  const wait = c.retryAfterMs ?? Math.min(cooldownMs * 2 ** (h.failures - 1), MAX_COOLDOWN_MS)
  h.cooldownUntil = now + wait
}
```

```ts
export class SessionLock {
  private held = new Set<string>()
  private aborts = new Map<string, number>()
  private seen = new Map<string, number>()

  constructor(
    private now: () => number = Date.now,
    private abortTtlMs = 10_000,
    private dedupTtlMs = 30_000,
  ) {}

  tryAcquire(id: string): boolean {
    if (this.held.has(id)) return false
    this.held.add(id)
    return true
  }
  release(id: string): void { this.held.delete(id) }

  markPluginAbort(id: string): void { this.aborts.set(id, this.now() + this.abortTtlMs) }
  consumePluginAbort(id: string): boolean {
    const exp = this.aborts.get(id)
    if (exp === undefined) return false
    this.aborts.delete(id)
    return exp >= this.now()
  }

  isDuplicate(key: string): boolean {
    const t = this.now()
    for (const [k, exp] of this.seen) if (exp < t) this.seen.delete(k)
    if (this.seen.has(key)) return true
    this.seen.set(key, t + this.dedupTtlMs)
    return false
  }
}
```

```ts
import fs from "node:fs"
import path from "node:path"

export interface SessionRecord { sticky?: string; origin?: string; switchCount: number; updated: number }

const TTL_MS = 14 * 24 * 3600 * 1000
const MAX_SESSIONS = 500

export class StateStore {
  private sessions: Record<string, SessionRecord> = {}
  constructor(private file: string, private now: () => number = Date.now) {}

  load(): void {
    try {
      const raw = JSON.parse(fs.readFileSync(this.file, "utf8"))
      if (raw && raw.v === 1 && typeof raw.sessions === "object") this.sessions = raw.sessions
    } catch { this.sessions = {} }
    this.prune()
  }

  get(id: string): SessionRecord {
    return this.sessions[id] ?? { switchCount: 0, updated: 0 }
  }
  set(id: string, r: SessionRecord): void { this.sessions[id] = r }

  private prune(): void {
    const t = this.now()
    for (const [id, r] of Object.entries(this.sessions)) if (t - r.updated > TTL_MS) delete this.sessions[id]
    const entries = Object.entries(this.sessions)
    if (entries.length > MAX_SESSIONS) {
      entries.sort((a, b) => b[1].updated - a[1].updated)
      this.sessions = Object.fromEntries(entries.slice(0, MAX_SESSIONS))
    }
  }

  save(): void {
    try {
      this.prune()
      fs.mkdirSync(path.dirname(this.file), { recursive: true })
      const tmp = this.file + ".tmp"
      fs.writeFileSync(tmp, JSON.stringify({ v: 1, sessions: this.sessions }), { mode: 0o600 })
      fs.renameSync(tmp, this.file)
    } catch { /* state is best effort; never affect the session */ }
  }
}
```

```ts
export interface OrChatArgs {
  baseUrl: string; key: string; model: string; system: string; user: string
  maxTokens: number; timeoutMs: number; zdr: boolean; fetchImpl?: typeof fetch
}

export async function orChat(a: OrChatArgs): Promise<{ text: string; costUsd?: number }> {
  if (!a.baseUrl.startsWith("https://")) throw new Error("OpenRouter baseUrl must be https")
  const f = a.fetchImpl ?? fetch
  const ctl = new AbortController()
  const timer = setTimeout(() => ctl.abort(), a.timeoutMs)
  try {
    const res = await f(`${a.baseUrl.replace(/\/$/, "")}/chat/completions`, {
      method: "POST",
      redirect: "manual",
      signal: ctl.signal,
      headers: { Authorization: `Bearer ${a.key}`, "Content-Type": "application/json" },
      body: JSON.stringify({
        model: a.model,
        max_tokens: a.maxTokens,
        provider: { data_collection: "deny", ...(a.zdr ? { zdr: true } : {}) },
        messages: [{ role: "system", content: a.system }, { role: "user", content: a.user }],
      }),
    })
    if (!res.ok) throw new Error(`OpenRouter request failed: HTTP ${res.status}`)
    const json: any = await res.json()
    const text = String(json?.choices?.[0]?.message?.content ?? "").trim()
    if (!text) throw new Error("OpenRouter returned an empty completion")
    const cost = typeof json?.usage?.cost === "number" ? json.usage.cost : undefined
    return cost === undefined ? { text } : { text, costUsd: cost }
  } finally {
    clearTimeout(timer)
  }
}
```

```ts
import type { FailureKind, OcMessage } from "./types"
import type { RelayConfig } from "./config"
import type { orChat } from "./openrouter"
import { RELAY_MARKER } from "./defaults"
import { isSensitivePath, redact, truncate } from "./redact"

export interface Extracted {
  lastUserText: string
  filesTouched: string[]
  toolCalls: { name: string; status: "DONE" | "FAILED" | "UNKNOWN"; target?: string }[]
  todo: string[]
  transcript: string
}

const EDIT_TOOLS = new Set(["edit", "write", "patch", "multiedit"])
const statusOf = (s: string): "DONE" | "FAILED" | "UNKNOWN" =>
  s === "completed" ? "DONE" : s === "error" ? "FAILED" : "UNKNOWN"

export function extractFromMessages(msgs: OcMessage[], o: { maxToolChars: number; maxTranscriptChars: number }): Extracted {
  let lastUserText = ""
  const files: string[] = []
  const toolCalls: Extracted["toolCalls"] = []
  let todo: string[] = []
  const lines: string[] = []

  for (const m of msgs) {
    for (const p of m.parts) {
      if (p.type === "text") {
        const text = String((p as any).text ?? "")
        if (text.includes(RELAY_MARKER) || (p as any).synthetic) continue
        if (m.info.role === "user") lastUserText = text
        lines.push(`${m.info.role === "user" ? "USER" : "ASSISTANT"}: ${redact(truncate(text, o.maxToolChars * 4))}`)
      } else if (p.type === "tool") {
        const t = p as any
        const input = t.state?.input ?? {}
        const target: string | undefined = input.filePath ?? input.path ?? input.command ?? undefined
        toolCalls.push({ name: t.tool, status: statusOf(String(t.state?.status)), ...(target ? { target: String(target).slice(0, 200) } : {}) })
        if (EDIT_TOOLS.has(t.tool) && typeof (input.filePath ?? input.path) === "string") {
          const f = String(input.filePath ?? input.path)
          if (!files.includes(f)) files.push(f)
        }
        if (t.tool === "todowrite" && Array.isArray(input.todos))
          todo = input.todos.filter((x: any) => x.status !== "completed").map((x: any) => `${x.status}: ${x.content}`)
        const sensitive = typeof (input.filePath ?? input.path) === "string" && isSensitivePath(String(input.filePath ?? input.path))
        const out = sensitive ? "[output omitted: sensitive file]" : redact(truncate(String(t.state?.output ?? t.state?.error ?? ""), o.maxToolChars))
        lines.push(`TOOL ${t.tool} [${statusOf(String(t.state?.status))}]${target ? " " + String(target).slice(0, 120) : ""}: ${out}`)
      }
    }
  }
  let transcript = lines.join("\n")
  if (transcript.length > o.maxTranscriptChars) transcript = transcript.slice(transcript.length - o.maxTranscriptChars)
  return { lastUserText, filesTouched: files, toolCalls, todo, transcript }
}

export function renderHandover(template: string, vars: Record<string, string>): string {
  return template.replace(/\{\{(\w+)\}\}/g, (m, k: string) => (k in vars ? (vars[k] as string) : m))
}

export async function writeNarrative(
  deps: { chat: typeof orChat; cfg: RelayConfig; key: string },
  ex: Extracted,
): Promise<{ summary: string; costUsd?: number } | null> {
  try {
    const r = await deps.chat({
      baseUrl: deps.cfg.openrouter.baseUrl, key: deps.key, model: deps.cfg.handover.model,
      system: deps.cfg.handover.writerPrompt,
      user: `<transcript>\n${redact(ex.transcript)}\n</transcript>`,
      maxTokens: 900, timeoutMs: 45_000, zdr: deps.cfg.privacy.zdr,
    })
    if (r.text.length === 0 || r.text.length > 6000) return null
    return r.costUsd === undefined ? { summary: r.text } : { summary: r.text, costUsd: r.costUsd }
  } catch {
    return null
  }
}

export function buildHandover(a: { cfg: RelayConfig; ex: Extracted; from: string; to: string; reason: FailureKind; summary: string | null }): string {
  const calls = a.ex.toolCalls.slice(-30).map((t) => `- ${t.status} ${t.name}${t.target ? " " + t.target : ""}`).join("\n") || "- (none)"
  const tail = a.ex.transcript.slice(-3000)
  return renderHandover(a.cfg.handover.messageTemplate, {
    from: a.from, to: a.to, reason: a.reason,
    summary: a.summary ?? `(summary unavailable; recent transcript follows)\n${tail}`,
    toolCalls: calls,
    files: a.ex.filesTouched.map((f) => `- ${f}`).join("\n") || "- (none)",
    todo: a.ex.todo.map((t) => `- ${t}`).join("\n") || "- (none)",
    lastRequest: a.ex.lastUserText || "(none found)",
  })
}
```

```ts
export type NarrationEvent = "switch_done" | "exhausted" | "cap_reached" | "no_consent" | "handover_failed" | "config_invalid"
type Vars = { from?: string; to?: string; reason?: string; detail?: string }
type Verbosity = "off" | "quiet" | "normal" | "chatty"

const POOLS: Record<NarrationEvent, string[]> = {
  switch_done: [
    "[relay] {from} stopped ({reason}). Continuing on {to}.",
    "[relay] Switched {from} -> {to} ({reason}).",
  ],
  exhausted: [
    "[relay] No healthy model left in the chain. Staying put.",
    "[relay] No healthy model available: every model in the chain is unavailable right now.",
  ],
  cap_reached: [
    "[relay] Switch limit for this session reached. Not switching again.",
    "[relay] Too many switches in this session (limit reached); stopping here.",
  ],
  no_consent: [
    "[relay] Running local-only: set privacy.consent to enable LLM handover summaries.",
    "[relay] Handover summaries are off (no consent). Using the plain transcript tail.",
  ],
  handover_failed: [
    "[relay] Handover summary failed; used the plain transcript tail instead.",
    "[relay] Handover summary failed (could not write one); passing the recent transcript instead.",
  ],
  config_invalid: ["[relay] Config problem: {detail}"],
}
const QUIET_OK = new Set<NarrationEvent>(["exhausted", "cap_reached", "config_invalid"])

export function createNarrator(
  opts: { verbosity: Verbosity; tone: "plain" | "british" },
  rng: () => number = Math.random,
): (ev: NarrationEvent, v?: Vars) => string | null {
  const last = new Map<NarrationEvent, number>()
  return (ev, v = {}) => {
    if (opts.verbosity === "off") return null
    if (opts.verbosity === "quiet" && !QUIET_OK.has(ev)) return null
    const pool = POOLS[ev]
    let idx = Math.min(pool.length - 1, Math.floor(rng() * pool.length))
    if (pool.length > 1 && last.get(ev) === idx) idx = (idx + 1) % pool.length
    last.set(ev, idx)
    const detail = ev === "config_invalid" ? (v.detail ?? "") : ""
    return (pool[idx] as string)
      .replace("{from}", v.from ?? "?")
      .replace("{to}", v.to ?? "?")
      .replace("{reason}", v.reason ?? "?")
      .replace("{detail}", detail)
  }
}
```

```ts
import { createHmac, randomBytes } from "node:crypto"
import fs from "node:fs"
import path from "node:path"

export class SwitchLog {
  private salt: Buffer | null = null
  constructor(private dir: string, private enabled: boolean) {}

  private getSalt(): Buffer {
    if (this.salt) return this.salt
    const f = path.join(this.dir, "salt")
    try { this.salt = Buffer.from(fs.readFileSync(f, "utf8"), "hex") } catch { /* create below */ }
    if (!this.salt || this.salt.length !== 32) {
      this.salt = randomBytes(32)
      fs.mkdirSync(this.dir, { recursive: true, mode: 0o700 })
      fs.writeFileSync(f, this.salt.toString("hex"), { mode: 0o600 })
    }
    return this.salt
  }

  append(r: { ts: number; sessionID: string; from: string; to: string; kind: string; helperCostUsd?: number }): void {
    if (!this.enabled) return
    try {
      const session = createHmac("sha256", this.getSalt()).update(r.sessionID).digest("hex").slice(0, 16)
      const row = { ts: r.ts, session, from: r.from, to: r.to, kind: r.kind, ...(r.helperCostUsd !== undefined ? { helperCostUsd: r.helperCostUsd } : {}) }
      fs.mkdirSync(this.dir, { recursive: true, mode: 0o700 })
      fs.appendFileSync(path.join(this.dir, "switches.jsonl"), JSON.stringify(row) + "\n", { mode: 0o600 })
    } catch { /* logging is best effort */ }
  }
}
```

```ts
import type { ClientLike, ModelRef } from "./types"
import type { SessionLock } from "./session-lock"

const sleep = (ms: number) => new Promise<void>((r) => setTimeout(r, ms))

export async function performSwitch(
  d: { client: ClientLike; lock: SessionLock; abortTimeoutMs?: number; abortDelayMs?: number; log?: (m: string) => void },
  a: { sessionID: string; to: ModelRef; agent?: string; handoverText: string },
): Promise<void> {
  const log = d.log ?? (() => {})
  d.lock.markPluginAbort(a.sessionID)
  const outcome = await Promise.race([
    d.client.session.abort({ path: { id: a.sessionID } }).then(() => "ok" as const, () => "rejected" as const),
    sleep(d.abortTimeoutMs ?? 5000).then(() => "timeout" as const),
  ])
  if (outcome === "rejected") d.lock.consumePluginAbort(a.sessionID)
  await sleep(d.abortDelayMs ?? 300)

  // Fire without awaiting: session.prompt resolves only when the whole model turn is over.
  Promise.resolve(
    d.client.session.prompt({
      path: { id: a.sessionID },
      body: {
        model: a.to,
        ...(a.agent ? { agent: a.agent } : {}),
        parts: [{ type: "text", text: a.handoverText }],
      },
    }),
  ).catch((e: unknown) => log(`prompt failed: ${e instanceof Error ? e.message : String(e)}`))
}
```

```ts
import type { SessionRecord } from "./state"

export function decidePin(rec: SessionRecord, inputModelKey: string):
  { action: "pin"; to: string } | { action: "clear" } | { action: "none" } {
  if (!rec.sticky) return { action: "none" }
  if (inputModelKey === rec.sticky) return { action: "none" }
  if (inputModelKey === rec.origin) return { action: "pin", to: rec.sticky }
  return { action: "clear" }
}
```

```ts
import type { ClientLike, OcMessage } from "./types"
import { modelKey, parseModel } from "./types"
import type { RelayConfig } from "./config"
import { classify } from "./classifier"
import { buildChain, nextModel, recordFailure, type ModelHealth } from "./strategy"
import type { SessionLock } from "./session-lock"
import type { StateStore } from "./state"
import type { createNarrator, NarrationEvent } from "./narrator"
import type { SwitchLog } from "./switchlog"
import type { orChat } from "./openrouter"
import { buildHandover, extractFromMessages, writeNarrative } from "./handover"
import { performSwitch } from "./switcher"

export interface Deps {
  client: ClientLike
  cfg: RelayConfig
  lock: SessionLock
  state: StateStore
  health: Record<string, ModelHealth>
  narrate: ReturnType<typeof createNarrator>
  switchLog: { append: SwitchLog["append"] }
  env: Record<string, string | undefined>
  now: () => number
  chat: typeof orChat
  log: (m: string) => void
  switchOpts?: { abortTimeoutMs?: number; abortDelayMs?: number }
}

export class Controller {
  private warnedConsent = false
  constructor(private d: Deps) {}

  private async toast(ev: NarrationEvent, v?: Parameters<Deps["narrate"]>[1], variant: "info" | "warning" = "info") {
    const message = this.d.narrate(ev, v)
    if (!message) return
    try { await this.d.client.tui.showToast({ body: { message, variant } }) } catch { /* toast is best effort */ }
  }

  private async fetchMessages(id: string): Promise<OcMessage[]> {
    const r = await this.d.client.session.messages({ path: { id } })
    return r.data ?? []
  }

  async onSessionError(sessionID: string, rawError: unknown): Promise<void> {
    try {
      await this.handle(sessionID, rawError)
    } catch (e) {
      this.d.log(`onSessionError failed: ${e instanceof Error ? e.message : String(e)}`)
    }
  }

  private async handle(sessionID: string, rawError: unknown): Promise<void> {
    const d = this.d
    const c = classify(rawError)
    if (c.kind === "user_abort") { d.lock.consumePluginAbort(sessionID); return }
    if (!c.switchable) return

    const session = await d.client.session.get({ path: { id: sessionID } })
    if (session.data?.parentID) return

    const msgs = await this.fetchMessages(sessionID)
    const lastAsst = [...msgs].reverse().find((m) => m.info.role === "assistant")
    if (!lastAsst?.info.providerID || !lastAsst.info.modelID) return
    const current = `${lastAsst.info.providerID}/${lastAsst.info.modelID}`

    if (d.lock.isDuplicate(`${sessionID}:${lastAsst.info.id}:${c.kind}`)) return
    if (!d.lock.tryAcquire(sessionID)) return
    try {
      recordFailure(d.health, current, c, d.now(), d.cfg.cooldownMs)
      const rec = d.state.get(sessionID)
      const decision = nextModel({
        chain: buildChain(d.cfg, current), current, health: d.health, now: d.now(),
        switchCount: rec.switchCount, maxSwitches: d.cfg.maxSwitchesPerSession,
      })
      if (decision.action === "exhausted") {
        await this.toast(decision.reason === "switch_cap" ? "cap_reached" : "exhausted", {}, "warning")
        return
      }

      const ex = extractFromMessages(msgs, d.cfg.handover)
      const key = d.env[d.cfg.openrouter.keyEnv]
      let summary: string | null = null
      let helperCost: number | undefined
      if (d.cfg.privacy.consent && key) {
        const w = await writeNarrative({ chat: d.chat, cfg: d.cfg, key }, ex)
        if (w) { summary = w.summary; helperCost = w.costUsd } else await this.toast("handover_failed", {}, "warning")
      } else if (!d.cfg.privacy.consent && !this.warnedConsent) {
        this.warnedConsent = true
        await this.toast("no_consent")
      }

      const text = buildHandover({ cfg: d.cfg, ex, from: current, to: decision.to, reason: c.kind, summary })
      const agent = [...msgs].reverse().find((m) => m.info.role === "user")?.info.agent
      await performSwitch(
        { client: d.client, lock: d.lock, log: d.log, ...(d.switchOpts ?? {}) },
        { sessionID, to: parseModel(decision.to), ...(agent ? { agent } : {}), handoverText: text },
      )

      d.state.set(sessionID, {
        sticky: decision.to, origin: rec.origin ?? current, switchCount: rec.switchCount + 1, updated: d.now(),
      })
      d.state.save()
      d.switchLog.append({
        ts: d.now(), sessionID, from: current, to: decision.to, kind: c.kind,
        ...(helperCost !== undefined ? { helperCostUsd: helperCost } : {}),
      })
      await this.toast("switch_done", { from: current, to: decision.to, reason: c.kind })
    } finally {
      d.lock.release(sessionID)
    }
  }

  status(sessionID?: string): string {
    const d = this.d
    const rec = sessionID ? d.state.get(sessionID) : undefined
    const chain = buildChain(d.cfg, rec?.sticky ?? d.cfg.tiers.primary ?? "(current model)")
    return [
      `chain: ${chain.join(" -> ")}`,
      `mode: ${d.cfg.mode}`,
      `sticky: ${rec?.sticky ?? "none"}`,
      `switches: ${rec?.switchCount ?? 0}`,
      `consent: ${d.cfg.privacy.consent ? "on" : "off"}`,
      `key: ${d.env[d.cfg.openrouter.keyEnv] ? "set" : "missing"}`,
    ].join("\n")
  }
}
```

Note: `modelKey` is imported for later use by `index.ts`; remove the import here if the typecheck flags it as unused.

```ts
import type { Plugin } from "@opencode-ai/plugin"
import path from "node:path"
import { Controller } from "./controller"
import { configFile, dataDir, loadConfig } from "./config"
import { StateStore } from "./state"
import { SessionLock } from "./session-lock"
import { SwitchLog } from "./switchlog"
import { createNarrator } from "./narrator"
import { orChat } from "./openrouter"
import { decidePin } from "./pin"
import { modelKey, parseModel, type ClientLike } from "./types"

export const server = (async (input: any, _options?: unknown, envOverride?: Record<string, string | undefined>) => {
  const env = envOverride ?? process.env
  const client = input.client as ClientLike
  const { config: cfg, warnings } = loadConfig(configFile(env))
  const dir = dataDir(env)
  const state = new StateStore(path.join(dir, "state.json")); state.load()
  const log = (_m: string) => { /* v1.0: no file logging; keep silent to avoid leaking content */ }
  const narrate = createNarrator(cfg.narrator)
  const controller = new Controller({
    client, cfg, lock: new SessionLock(), state, health: {}, narrate,
    switchLog: new SwitchLog(dir, cfg.ledger.enabled), env, now: Date.now, chat: orChat, log,
  })
  let warned = false
  const warnOnce = async () => {
    if (warned || warnings.length === 0) return
    warned = true
    const message = narrate("config_invalid", { detail: warnings[0] })
    if (message) try { await client.tui.showToast({ body: { message, variant: "warning" } }) } catch { /* ignore */ }
  }

  return {
    config: async (c: any) => {
      c.command = { ...(c.command ?? {}), relay: { template: "relay status", description: "opencode-model-relay: show status" } }
    },
    event: async ({ event }: any) => {
      try {
        await warnOnce()
        if (event?.type === "session.error") {
          const { sessionID, error } = event.properties ?? {}
          if (typeof sessionID === "string") await controller.onSessionError(sessionID, error)
        }
      } catch { /* hooks must never throw */ }
    },
    "command.execute.before": async (i: any, out: any) => {
      try {
        if (i?.command !== "relay") return
        out.parts = []
        const message = controller.status(i.sessionID)
        await client.tui.showToast({ body: { message, variant: "info" } })
      } catch { /* ignore */ }
    },
    "chat.message": async (i: any, out: any) => {
      try {
        if (!i?.sessionID || !i.model) return
        const rec = state.get(i.sessionID)
        const d = decidePin(rec, modelKey(i.model))
        if (d.action === "pin") out.message.model = parseModel(d.to)
        else if (d.action === "clear") { state.set(i.sessionID, { switchCount: rec.switchCount, updated: Date.now() }); state.save() }
      } catch { /* ignore */ }
    },
  }
}) as unknown as Plugin

export default { id: "opencode-model-relay", server }
```
